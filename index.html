01 · ปัญหาที่พบ

ปัญหาจากระบบ Excel เดิม

บริษัทใช้ Excel จัดเก็บข้อมูลวัตถุดิบ แต่พบข้อจำกัดหลายด้าน ส่งผลต่อกระบวนการติดตามและการวางแผนการผลิต

⏳

ข้อมูลล่าช้า

ไม่สามารถแสดงข้อมูล Real-time ได้ ผู้ปฏิบัติงานตรวจสอบสถานะวัตถุดิบไม่ทันเวลา

📂

ข้อมูลกระจัดกระจาย

แยกเป็นหลายไฟล์หลาย Sheet โครงสร้างไม่เป็นระบบเดียวกัน ต้องเสียเวลารวบรวมทุกครั้ง

⚠️

เกิดความผิดพลาด

กรอกข้อมูลด้วยมือทำให้เกิดข้อมูลซ้ำซ้อน และโอกาสเกิด Human Error สูง

🚫

ตัดสินใจไม่ทันเวลา

ผู้บริหารขาดข้อมูล ณ ปัจจุบัน โดยเฉพาะในช่วงที่ต้องวางแผนการผลิตเร่งด่วน

↓

ผลกระทบ: กระบวนการติดตามปริมาณหัวมันสำปะหลังและการวางแผนการผลิตไม่มีประสิทธิภาพ จำเป็นต้องมีระบบ Dashboard ที่แสดงผลได้แบบ Real-time

03 · วิธีดำเนินการ · ETL Process

กระบวนการ ETL + Power BI

STEP 01 · EXTRACT

ดึงข้อมูลจาก Excel

เชื่อมต่อไฟล์ Excel รายเดือน (ม.ค.–ต.ค. 2568) เข้าสู่ Power BI โดยเลือก Data Source เป็น Excel

STEP 02 · TRANSFORM

แปลงข้อมูลด้วย Power Query

Unpivot ตาราง Cross-Tab → แถวปกติ, ล้างข้อมูล, จัดโครงสร้างคอลัมน์ใหม่ให้พร้อมวิเคราะห์

STEP 03 · LOAD

โหลดเข้า Data Model

Power BI โหลดข้อมูลเข้า Data Model แล้วสร้าง Visualization กราฟเส้น กราฟวงกลม และตารางสรุป

STEP 04 · AUTOMATE

รีเฟรชอัตโนมัติ

ตั้ง Flow ใน Power Automate แบบ Recurrence Trigger ทุก 1 นาที → Dashboard อัปเดตข้อมูลตลอดเวลา
